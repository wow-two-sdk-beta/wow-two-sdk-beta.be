# Storage.S3

`S3BlobRepository` — `IBlobRepository` over one S3-compatible bucket: AWS S3, Cloudflare R2, MinIO, Hetzner, Spaces.

```csharp
// AWS: region + default credential chain (environment, profile, instance role)
services.AddS3BlobStorage(o => { o.BucketName = "acme-prod"; o.Region = "eu-central-1"; });

// S3-compatible endpoint: path-style, static keys
services.AddS3BlobStorage(o =>
{
    o.BucketName = "acme";
    o.ServiceUrl = new Uri("https://<account>.r2.cloudflarestorage.com");
    o.AccessKey = cfg["S3:AccessKey"];
    o.SecretKey = cfg["S3:SecretKey"];
    o.KeyPrefix = "ocharo";                    // optional folder inside a shared bucket
});
```

- A `ServiceUrl` switches on path-style addressing and on-demand checksums, which S3-compatible services expect.
- Non-seekable uploads spool to a temporary file first, so the object length is known; pass seekable streams to skip it.
- `ListAsync` pages through `ListObjectsV2`; listings carry no content type (call `GetInfoAsync` for one blob).
- The bucket must exist; creating it stays with infrastructure.
